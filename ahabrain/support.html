AhaBrain SUPPORT

帮助与支持

关于游戏体验、训练计划、会员订阅或其他问题，你可以在这里找到常见解答并提交反馈。

需要进一步帮助？

请通过 GitHub 问题反馈区告诉我们发生了什么。建议提供应用版本、设备型号和重现步骤，以便排查。

通过 GitHub 提交反馈

注意：GitHub 反馈会公开显示，且提交需要 GitHub 账号。请勿发布姓名、邮箱、密码、购买凭证或其他敏感信息。

常见问题

怎样开始脑力训练？

打开灵光大脑，从探索页选择游戏，或从训练计划入口开始。具体入口取决于 App 版本。

如何恢复已经购买的会员？

如果当前版本提供「恢复购买」，可在会员页面使用该功能。若入口尚未开放或恢复失败，请向我们反馈。

如何管理或取消自动续期订阅？

在 iPhone 上打开「设置」→ Apple 账户 →「订阅」，找到 AhaBrain 后管理或取消订阅。

如何反馈游戏或训练问题？

请描述游戏名称、操作步骤、预期表现及实际表现，并提供设备和 App 版本。不要上传个人敏感信息。
